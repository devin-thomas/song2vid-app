# Song2Vid

Song2Vid is a tiny native macOS app that turns a song and an image into a video. Choose an audio file and a picture, pick a frame shape and resolution, and save an MP4.

This repo is also a worked example of planning a project with Grill to Build and building it with a chief-of-staff agent workflow, where one coordinating agent dispatches subagents ticket by ticket.
