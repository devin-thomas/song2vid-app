# Domain docs

Single-context layout:

- `GLOSSARY.md`: canonical domain terms. Use these words in code, tests, UI text and commits.
- `ADR.md`: one append-only decision record (not `docs/adr/`).
- `PROJECT.md`: the current brief and scope. `SPEC.md`: the required behavior.
- `Ideas.md`: out of scope. Never build from it unless a ticket says so.
