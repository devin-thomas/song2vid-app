# Premium ledger: Song2Vid for Windows

One row per rule of the desktop-app skill's premium bar (`references/premium-bar.md`, rules 1 to 111 and 41b), as ADR-023 and SPEC section 28 ask. A rule **applies** (its check is named, and its verdict per run is **verified**, **unmet** or **unverified**) or is **N/A** with a one-line reason. Rule wording and check names are the skill's, copied from skills commit `48b054d16de2fbcdcb30487471967dda176b469b` (branch `beta`); `windows/app/PROVENANCE.md` names the same commit.

Status of this file: written by S2V-028 before any screen existed; S2V-030 (2026-11-24) recorded the verdicts that the headless gates give; S2V-031 (2026-11-25) filled every remaining row: each rule is **applies** with a verdict (`verified` with the gate that proves it, `partly verified` with what is left, or `unverified` with the reason) or **N/A** with its reason. The unverified rows are the list for the release notes (SPEC 28): 2, 4, 16, 19, 21, 23, 24, 28, 30, 32, 33, 34, 39, 42, 54, 61, 62, 64, 78, 79, 82, 89, 100, 102 (and the parts of the `partly verified` rows that say so). `qa:visual` on Windows, `shell:evidence`, `measure:focus` and `measure:memory` did not run in S2V-031 (Titan refused the build's ssh key partway through, see the ticket); they belong to S2V-032 or the next time Titan answers. The N/A rows are the ones SPEC 28 lists as known, "unless the build shows otherwise"; a build that shows otherwise changes the row and says why. The handoff says "passes the automated bar", lists every row not verified, and never says premium (SPEC 28).

Where each check runs (SPEC 28, as the coordinator changed it for this release: Titan, with the no-activate launch rules, in place of the DeskMini): headless gates (`typecheck`, `test`, `shell:check`, `qa:audit`, `qa:visual`, `fuses:check`, `qa:planted`) on the Mac and on Titan; every check that opens a window (`qa:crash`, `qa:kill`, `shell:evidence`, `measure:focus`, the installed check) on the DeskMini.
