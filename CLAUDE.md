# Song2Vid

A native macOS app that turns one song and one image into an MP4. Start with `PROJECT.md`, then `SPEC.md`.

This repo is **public**. Never commit tokens, account IDs, emails, IP addresses or `/Users/...` paths. Commits must be authored as the repo-local identity (`devin` with the noreply address), with no AI co-author lines.
